# 1時間ロック (OneHourLock)

1日のスマホ使用時間（画面ONの時間）が **1時間** を超えると、
全画面のロック画面を表示して **0:00 まで端末を操作できなくする** Android アプリです。

## 仕組み

- `UsageStatsManager` の画面ON/OFFイベントから、今日 0:00 からの画面ON時間を計算
  （アプリが停止していた時間も正しくカウントされます）
- 常駐サービスが残り時間を監視し、通知に表示。残り5分で警告通知
- 上限を超えると、他アプリの上に全画面オーバーレイを表示し、タッチと戻るキーを吸収
- 0:00 になると自動で解除
- 端末再起動・アプリ更新後も自動で監視を再開
- （任意）デバイス管理者を有効にするとアンインストール不可に。
  オーバーレイ権限を外された場合も画面ロックをかけ続けます

### 安全のための例外

- 電話の着信中・通話中はロックを一時的に外します
- ロック画面の「緊急通報」ボタンで電話アプリを開けます（60秒間ロック解除）

## 初回セットアップ

アプリを開いて、画面の指示に従って以下を許可してください。

1. 使用状況へのアクセス（必須）
2. 他のアプリの上に重ねて表示（必須）
3. バッテリー最適化の対象外（推奨）
4. デバイス管理者（推奨）

## ビルド

```sh
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

GitHub Actions でも push ごとに APK がビルドされ、Artifacts からダウンロードできます。

要件: minSdk 28 (Android 9) / targetSdk 35
